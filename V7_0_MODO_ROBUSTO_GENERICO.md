# V7.0 — Modo Robusto / Conclusão Genérica

Objetivo: parar de transformar cada estudo num caso especial de cartões executivos.

- O painel executivo mostra apenas: viabilidade, área de referência, enquadramento, uso dominante, parâmetros urbanísticos (remissão para análise técnica), validação e evidência.
- Pisos, implantação, índices, ABC e fogos deixam de ser requisitos do painel executivo. Permanecem no relatório técnico quando suportados.
- O bloco “Decisão Preliminar” do PDF usa a mesma linguagem genérica em qualquer município.
- Foi removida a segunda pesquisa regulamentar automática só para preencher números em falta; evita que uma tentativa de “completar” o relatório introduza nova contradição.
- Continua a existir a correção especial apenas quando os anexos contêm claramente projeto/PIP e o modelo o ignora.
- A classificação e o uso são limpos/encurtados para evitar duplicações e texto demasiado longo nos cartões.

A filosofia desta versão é: menos números no resumo, mais estabilidade; detalhe técnico apenas no corpo fundamentado do relatório.
